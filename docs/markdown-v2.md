# GymFlow Markdown v2

У каждого файла есть YAML с версией, UUID и видом документа. В сессии также указаны дата, общий статус и UUID участников. JSON в комментарии GymFlow остаётся каноническим. Человекочитаемый блок под ним обновляется при сохранении. Ручные заметки и однострочный пользовательский YAML сохраняются вне служебного блока.

## Модель

- `Program` хранит упорядоченные `WorkoutTemplate` и правила расписания. У плана упражнения могут быть персональные списки подходов.
- `TrainingSession` объединяет одну или несколько `ParticipantWorkout` и сохраняется одним файлом. Связи между документами используют UUID.
- `ParticipantWorkout` хранит профиль, снимок названия и UUID шаблона, собственный статус, упражнения, UUID текущего упражнения, подходы, результаты, RIR и метрики. Протокол конкретной тренировки остаётся доступен после изменений программы.
- Индивидуальный статус может быть Planned, Active, Paused, Completed, Skipped или Cancelled. Общее завершение сохраняет записанные подходы. Индивидуальная тренировка с оставшимися запланированными подходами получает Cancelled, если спортсмен ещё явно не завершил её.
- `weightKnown` и `repsKnown` различают числовое значение и пропуск в заметке. `maxEffort` задаёт открытый план по повторам. Известные повторы с неизвестным весом учитываются как повторения. Объём требует известных весов, повторов и трактовки нагрузки.

В отчёте упражнения сгруппированы по участникам. Результаты заменённых упражнений остаются в истории, а индивидуальная позиция доступна при следующем открытии.

## Миграция и надёжность

Чтение v0/v1 переносит общий список в личные списки с сохранением порядка, UUID упражнений и подходов, снимков замен, результатов, RIR и метрик. UUID индивидуальной тренировки стабильно вычисляется из UUID сессии и профиля. Открытие и предпросмотр могут работать с исходным файлом. Схема v2 записывается при сохранении.

Перед изменением старого документа GymFlow атомарно сохраняет исходный текст в приватной папке приложения. Такие файлы входят в экспорт резервного архива в разделе «До миграции». Дополнительно журнал проверяет SHA-256 внешнего файла и перечитывает запись после сохранения. При внешней правке можно выбрать версию вручную. Неизвестные будущие версии отклоняются.

Room хранит индекс и ожидающие записи. Разобранные документы переиспользуются в ограниченном кэше. Перелистывание фиксирует положение после завершения жеста. Подтверждение фактического подхода и выбор следующего участника проходят через один снимок сессии.

Предыдущая версия описана в [Markdown v1](markdown-v1.md).
