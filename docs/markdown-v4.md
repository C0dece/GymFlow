# GymFlow Markdown v4

Формат расширяет [Markdown v3](markdown-v3.md). Версии 0-3 читаются с прежними значениями по умолчанию. При изменении старого файла приложение сохраняет исходник перед записью v4. JSON остаётся внутри Markdown, Room и SAF используют существующий журнал.

- `movement_family` хранит семейство. В каталоге `Exercise.movement` указывает семейство, исходное упражнение, тип вариации, оборудование, ограничения и виды измерений. UUID упражнения идентифицирует историю. Сравнение также проверяет тип нагрузки, оборудование и описание вариации.
- `movement_track` хранит личный статус, критерий, шаг предложения, интервал, приоритет, паузу и ограничения. UUID строится из профиля и упражнения. Предложения не меняют план без действия пользователя.
- `movement_skill` хранит уровни с зависимостями и критериями. `skill_attempt` хранит измеренную попытку участника в отдельном документе. Циклические зависимости отклоняются.
- Подход может иметь назначение `role` и дополнительные факты `Actual.measurements`. Отсутствующие вес и повторы по-прежнему маркируются отдельно. Разминка из старой схемы сохраняет назначение.
- В блоке программы можно указать роль, вариант выбора движения и связанный навык. При адаптации сохраняется `originalPlan`, а отложенные минимальным режимом подходы помечаются `deferred`. Смена вариации переносит оставшееся число подходов и хранит выполненные результаты прежнего движения.
- Новые документы находятся в папке `Движения`. Экспорт сохраняет их вместе с программами и историей.
