# GymFlow

Нативный офлайн-дневник силовых тренировок на русском. Можно начать занятие сразу, подключить локальную папку Obsidian позже и добавить партнёров по ходу тренировки.

## Запуск на Windows

Нужны PowerShell, JDK 17 или совместимый JDK, Android SDK и аппаратная виртуализация. Android Studio пригодится для IDE и Compose Preview. Скрипты работают через Android SDK Command-line Tools и Gradle Wrapper.

```powershell
.\setup-dev.ps1 -Install
.\run-app.ps1
```

При подготовке SDK подтвердите лицензии в терминале. При наличии готового SDK достаточно запустить `setup-dev.ps1` без `-Install`. Скрипты используют `ANDROID_HOME`, `ANDROID_SDK_ROOT`, игнорируемый Git файл `local.properties` или типичные пути установки. Параметр `-Sdk` указывает SDK для подготовки. Для последующих команд в той же сессии можно задать `$env:ANDROID_HOME`.

`run-app.ps1` открывает AVD `GymFlow_Test`, устанавливает Debug APK и запускает приложение. `start-emulator.ps1` запускает только AVD. Параметр `-Headless` удобен для проверок без перехвата фокуса. Если нужный AVD уже открыт, скрипт использует его. Для фонового запуска используется программный рендерер. При необходимости отдельно запустите AVD командой `start-emulator.ps1 -Headless -Gpu swiftshader -ColdBoot`. Для компактного профиля:

```powershell
.\setup-dev.ps1 -Install -Avd GymFlow_Compact -Compact
.\run-app.ps1 -Avd GymFlow_Compact
```

Установочную конфигурацию составляют Gradle 9.6, AGP 9.4.1, Kotlin Compose/Serialization 2.4.10, Compile SDK 37.2, Target SDK 36 и Min SDK 26. Для настройки эмулятора 36 используется образ Google APIs, x86_64 на обычном ПК. На ПК, где проводилась проверка, созданы `GymFlow_Test` (Pixel 7) и `GymFlow_Compact` (Pixel 4) на Android 14 с Google APIs и WHPX. Загрузка образа Android 16 прерывалась по тайм-ауту. Для установки Android 16 рядом с ними можно использовать `setup-dev.ps1 -Install -Avd GymFlow_Android16`.

Документация Android для [совместимости Gradle](https://developer.android.com/build/releases/about-agp), [Compile SDK](https://developer.android.com/reference/tools/gradle-api/9.4/com/android/build/api/dsl/CompileSdkSpec) и [ускорения эмулятора](https://developer.android.com/studio/run/emulator-acceleration).

## Папка Obsidian

1. Создайте в локальном хранилище Android отдельную папку GymFlow, например внутри хранилища Obsidian.
2. На главной или в настройках нажмите «Выбрать папку». Подтвердите доступ в системном окне Android.
3. GymFlow загрузит свои Markdown-записи. Новые записи появятся в подкаталогах «Тренировки», «Программы», «Упражнения» и «Участники». Синхронизацией устройств управляет выбранный вами сервис.
4. При временной потере доступа новые результаты сохраняются на устройстве. После возврата разрешения нажмите «Обновить». При конфликте в настройках можно выбрать локальную версию или версию из папки.
5. Архив Markdown можно экспортировать из настроек. Резервный архив также включает последние предшествующие версии, имеющиеся в журнале.

Формат, структура данных, миграции и восстановление описаны в [GymFlow Markdown v5](docs/markdown-v5.md).

## Тренировки и планы

- «Посмотреть план» открывает черновик с порядком упражнений, подходами, предыдущими результатами и доступным расчётом объёма. Кнопки «Сохранить план» и «Начать тренировку» подтверждают изменения.
- В общей сессии добавьте участника через меню и выберите его тренировочный день. Верхние вкладки переключают людей. Свайп карточки перелистывает упражнения выбранного участника. Значок «+» добавляет упражнение ему или нескольким отмеченным людям.
- Автопереключение использует оставшиеся подходы каждого участника. «Закрепить участника» приостанавливает автоматику до смены вкладки или снятия закрепления. Меню также позволяет поставить индивидуальную тренировку на паузу, убрать её из очереди или завершить.
- «Повторить тренировку» открывает предпросмотр. После подтверждения создаётся сессия с новым UUID и пустыми фактическими подходами. Можно выбрать день программы, спланированную тренировку или пустой план.

## Прогрессия

1. Откройте «Прогрессия» с главного экрана или из настроек. Выберите участника и упражнение, чтобы проверить решение на известной истории.
2. В «Настроить прогрессию» выберите область и стратегию. По умолчанию действует консервативная двойная прогрессия. Расширенные параметры задают шаги оборудования, целевой RIR, окна анализа и пределы. «Пользовательская» открывает конструктор условий и действий с приоритетами и предпросмотром.
3. Завершите тренировку. В «Истории рекомендаций» доступны исходные данные, причины и предложения для каждого участника.
4. Откройте следующий план, разверните упражнение и выберите «Принять», «Оставить прежний план» или «Изменить вручную». Подтвердите сохранение или начало. Решение и выбранный план сохраняются вместе с сессией в отдельных полях, а фактические результаты вводятся в ходе тренировки.

Доступны автоматический режим, двойная и линейная прогрессия, прогрессия повторений и объёма, RIR, волны, поддержание, разгрузка и пользовательские правила. В настройках профиля можно архивировать участника. Его тренировки и рекомендации остаются в истории.

## Движения и навыки

Откройте «Прогрессия» → «Движения и навыки». В каталоге можно связать существующее упражнение с семейством, указать исходное движение и включить дополнительные измерения. Для участника можно задать роль, цель и периодичность. Уровни навыков подтверждаются измеренными попытками.

В настройках упражнения программы доступны тип блока и выбор вариации. В тренировке меню упражнения открывает вариации и проверку нагрузки, а меню участника позволяет поменять объём. Замена использует оставшиеся подходы. Вес, повторы и дополнительные измерения для нового движения указываются отдельно.

## Цикл по завершённым занятиям

В разделе «Программа» можно добавить «Силовой фундамент 8» или настроить собственный цикл. Число посещений задаёт ритм, а последовательность меняется после зачтённого занятия. На главной откройте карточку «Следующая по циклу». Там доступны план, внеочередной день и продолжение после достижения цели.

В редакторе дня можно добавлять и переупорядочивать блоки. Отдых и шаблон разминочных подходов задаются в параметрах упражнения. Кардио фиксируется по введённым измерениям и отображается в истории. Через меню упражнения можно пропустить необязательный блок.

## Импорт недельных заметок

Конвертер на Node.js преобразует W43 и W44 в отдельную папку GymFlow. В режиме чтения он берёт историю из завершённой W43 и план из W44, включая порядок, персональные веса и разминки. Неизвестные значения помечены знаком вопроса. Для подходов «макс» фактические повторы вводятся при подтверждении.

```powershell
node .\scripts\import-obsidian.mjs "2026-W43 (Неделя 1).md" "2026-W44 (Неделя 2).md" ".\GymFlow-Import"
node --test .\scripts\import-obsidian.test.mjs
```

Перенесите выходную папку в `Documents` на Android, затем выберите её в настройках GymFlow. Для этой установки готовая локальная копия находится в `qa-output/GymFlow-Obsidian-v2`. Изменения занятия будут записываться в выбранную папку GymFlow.

## Сборка и проверки

```powershell
.\build-apk.ps1
.\test-all.ps1 -Avd GymFlow_Compact -Headless
.\test-all.ps1 -JvmOnly
.\scripts\test-vault.ps1 -Seed
.\scripts\test-vault.ps1 -Destination .\qa-output\vault
```

Debug APK находится в `app/build/outputs/apk/debug/app-debug.apk`. Для телефона с Android 8 или новее можно установить его через `adb -s <серийный-номер> install -r app/build/outputs/apk/debug/app-debug.apk` при включённой отладке по USB. Скрипт `build-apk.ps1 -Release` собирает неподписанный APK для последующей подписи владельцем. Подпись распространяемой сборки настраивается отдельно.

JUnit, lint и проверки Android-зависимостей запускаются через `test-all.ps1`. JUnit и lint создают отчёты в `app/build/reports`. Инструментальный запуск сохраняет протокол, скриншоты и логи в `qa-output`. Инструментальные сценарии выбирают свою папку `Documents/GymFlow_QA_*` на эмуляторе через системное окно SAF. Для инструментальных тестов используйте отдельный AVD со стандартным английским интерфейсом Android. В результатах тестов есть проверка записи и чтения файлов, сетов, переключения участников, планирования и восстановления. PNG из UI-тестов можно выгрузить через ADB из `/sdcard/Android/data/app.gymflow/files/qa`.

## Структура

- `domain` содержит модели, расписание, статистику и кодек Markdown.
- `data` реализует индекс и журнал Room, DataStore и операции SAF.
- `GymModel` связывает операции с состоянием и очередью сохранения.
- `ui` содержит разделы Jetpack Compose, редакторы и навигацию.

## Ограничения

- Конвертер недельных заметок рассчитан на таблицы W43/W44. Приложение читает собственный Markdown v0, v1, v2, v3, v4 и v5.
- Фоновое планирование зависит от WorkManager. При запуске приложение проверяет текущую локальную дату по часам Android.
- SAF не предоставляет универсальную атомарную замену и блокировку для внешних редакторов. При повреждении GymFlow сохраняет локальную версию и предлагает разрешить конфликт.
- Для подключения рабочей папки нужен провайдер SAF с разрешением на чтение и запись. Поведение облачных и OEM-провайдеров может отличаться от стандартного локального Android DocumentsProvider.
